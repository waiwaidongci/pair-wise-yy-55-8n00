# 音乐总谱编辑、移调与分谱出版准备平台

源提示词编号：12。支持多声部总谱、VexFlow 五线谱、音符与力度/连音/表情编辑、移调乐器、分谱提取与换页提示音、版本差异、评论锚点、撤销重做、打印和未保存恢复。

## 巡演勘误交接（离线改稿合并）

- **出发前留基线**：`重建出发基线` 为每个声部分声部记录小节内音符标识顺序、内容指纹与移调值（`buildTrackBaseline`）。
- **回传按标识与字段合并**：离线包（`OfflineBundle`）永不整包覆盖。以出发值为 base、工作室当前值为 studio、离线值为 offline 做字段级三方比对（`buildPlan`）：
  - 只有离线侧改 → 进入逐项写入计划；
  - 双方都动过同一字段 / 移调 / 删除 → 进**复核区**，展示三方取值，人工裁决采用离线值或保留工作室（指挥批注）值。
- **失败可续传**：写入逐操作落盘，cursor 持久化到 localStorage；第 N 项失败时前 N-1 项保留，`接着重试` 从断点继续，不重放。
- **版本不重复**：同一交接包（或同次保存）以 `versionId` 守卫只形成一次版本；版本是含全声部音符、移调、评论、出版检查的不可变快照，旧版本继续可查。
- **失效重算**：音符或移调一变，锚定该音符/声部的评论置 `stale`（按音符标识重新定位小节，不删除），对应出版检查（拼写/节奏/移调）立即重算；指挥确认后刷新指纹解除失效。
- **旧草稿升级**：旧评论只有小节号时，先按内容关键词回填声部编号、音符标识与指纹再参与合并；识别不出的声部保留为人工指派。

演示数据：圆号包触发双方力度冲突（复核区）+ 增删音；单簧管包在第 3 项写入处断网一次，且单方移调 -2 → -5。

React、Ant Design、Redux Toolkit、React Router、RTK Query、VexFlow、Vite、TypeScript。
